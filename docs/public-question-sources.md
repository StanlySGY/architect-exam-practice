## 当前题库的既有审计基线

项目既有来源审计曾检查相邻题库快照：选择题 1,947 道（整理真题 1,422、模拟题 525），案例 132 道，论文 104 道。该数字是某次外部题库快照的结构统计，不代表官方完整覆盖，也不代表答案已逐题核实；当前题库若更新，应重新执行 npm run audit:bank-traceability 和答案风险审计。

审计还指出题目级 URL、页码或条款定位不足；sourceFile 路径字段非空不代表文件真实可打开。无官方原卷或可定位证据时，不得把第三方答案标记为官方答案，也不得因为解析文本非空就视为正确。

## 推荐的题目接入规则

1. 优先接入能提供原始来源、考期、题号、题型和可定位出处的数据。
2. 保存来源类型（官方原卷、官方标准/教材、第三方整理、模拟题、AI 参考）和答案可信度；真题题面与答案可信度是两条不同的元数据。
3. 对回忆版、OCR 重建题和缺图题明确标记，不把推测内容伪装成原题。
4. 保留原始题面、选项、答案、解析的版本变化记录；修改答案后必须重新审校。
5. 未获明确许可的题目只在本地授权使用，不提交到公共 GitHub，也不随应用静态部署。
6. 模拟题、AI 生成题用于补充知识点训练，不替代真题；生成题在本项目中仍需人工审校才可进入正式学习。
