# 备考能力建设与验收记录（2026-11-03）

## 本轮目标

将“架构师练习室”从页面集合推进为可追踪的学习流程和更贴近现行考试结构的训练工具。所有正式章节练习仍执行人工审校门槛；本轮没有批量批准未经核验的生成题，也没有调用真实模型、消耗外部模型额度。

## 已实现

### 学习单元与进度

- 学习页分别显示核心知识、学习价值、机制/方法、场景、例子、考试关注点、易混淆概念和常见陷阱，不再用一个字段覆盖另一个字段。
- 使用课程内容文件中逐单元维护的自检问题；勾选状态按学习单元持久化。
- 必须完成当前单元自检后才能推进阅读进度。
- 展示该单元登记的资料依据、支持范围、来源边界及核验状态；没有可追溯证据时明确提示回查指定版本教材。
- 学习完成后只使用精确知识点匹配、且满足正式练习资格的题目；没有匹配题时不再用同章节题目凑数。

### 题库状态与正式练习

- 章节和小节目录区分正式可练、待审校和隔离题数量。
- 正式章节练习仍只纳入通过人工事实核验、证据定位完整、审核版本与当前题目一致的生成题。
- 首页明确说明章节题暂不可练时可以进入真题套卷或进行题目审校，不把候选题伪装成正式练习。

### 连续考试训练

- 新增按考期启动的 240 分钟综合知识 + 案例分析连续模拟。
- 只有同一考期具备完整 75 道综合知识题和至少 3 道同来源案例题时才开放入口。
- 综合知识阶段最短 120 分钟、最长 150 分钟；手动提前交卷由服务端拒绝，150 分钟到时自动交卷。
- 案例阶段继承 240 分钟总时限的剩余时间，按同一考期、同一来源组卷。
- 案例阶段仅在本场考试开始满 180 分钟后开放交卷（即考试结束前 60 分钟）。前端倒计时门禁、评分前服务端门禁和成绩落库门禁三层校验一致。
- 综合知识交卷结果与案例试卷关联；页面刷新后可以恢复待进入的案例阶段或正在进行的案例卷，重复继续不会更换题目或重置计时。
- 两科分别按 75 分制 45 分合格线展示，不以两科总分相互抵消。论文仍作为独立 120 分钟训练，不包含在本连续模拟内。

### 内容质量审计

- npm run audit:learning-content 除全文完全重复检测外，新增已知模板句式启发式扫描。
- 模板扫描只用于定位可能过于通用的教学字段，不判断事实正确性；命中不等于错误，未命中也不代表讲解充分。

## 验收

- npm run lint 通过。
- 本轮全量 npm test：354/354 通过。
- 连考服务层测试覆盖 119 分钟提前交卷拒绝、120/150 分钟阶段切换、案例剩余时间、240 分钟到时拒绝首次进入、不完整考卷拒绝、同一案例卷幂等恢复。
- 连考案例交卷窗口测试覆盖综合知识 120 分钟和 150 分钟两种切换：总考试开始第 179 分钟拒绝进入评分，第 180 分钟允许进入评分；服务端评分前和保存成绩时均实施门禁。
- Chrome 实测 12 个主导航页面；桌面布局正常；390px 移动视口无横向溢出。
- Chrome 网络与运行时检查无异常请求、404 或未捕获异常。
- 2025 年下半年真题目录核验为 75 道综合知识、8 道案例，连考按钮正确启用；没有真正启动考试或修改答题记录。
- 实测 1.1“系统架构概述”精确巩固接口返回 0 道匹配题，避免再混入法律法规或英语阅读题。
- 没有进行真实模型生成和 AI 评分调用。

现行考试规则以官方通知为准：综合知识与案例分析连考共 240 分钟，综合知识阶段 120–150 分钟，案例阶段仅可在考试结束前 60 分钟交卷。参考：湖南省计算机软件资格考试办公室 2026-10-16 批次通知（https://gxt.hunan.gov.cn/gxt/rkb/jsjtzgg/202610/t20261016_34082960.html）；福建省工业和信息化厅 2026-10-21 考生须知（https://gxt.fujian.gov.cn/zwgk/ztjj/fjrkzl/xxfb/ksxx/202610/t20261021_7238739.htm）。

## 使用入口

本机启动后打开 http://127.0.0.1:3210/。在“模拟考试”选择完整考期，满足题量条件时使用“按此考期开始 240 分钟连考”。2025 年下半年当前具备完整的 75 道综合知识和 8 道案例，可作为一次连考训练样本。

## 本机部署

仓库包含 deploy/architect-exam-practice.service。当前用户级 systemd 服务已安装并启用，服务名为 architect-exam-practice.service，监听 127.0.0.1:3210，失败时自动重启。

常用管理命令：

- 查看：systemctl --user status architect-exam-practice.service
- 重启：systemctl --user restart architect-exam-practice.service
- 停止：systemctl --user stop architect-exam-practice.service
- 查看日志：journalctl --user -u architect-exam-practice.service -n 100 --no-pager

服务读取项目目录的本地 .env；密钥不写入 unit 文件和仓库。当前部署是 WSL/本机用户服务，不代表已发布到公网托管平台。
