范围：当前工作区，包含已修改、未跟踪的 `src/service/` 等文件；未改动产品代码、原始学习数据，也未进行实际计费模型调用。隔离数据库启动服务并检查桌面 1440×900、移动 390×844 页面；运行 `npm test`（63/63 通过）及主要文件 `node --check`，以浏览器与 curl 验证健康检查和 10 个只读 API 返回 200。移动端 Lighthouse 快照：Accessibility 96、Best Practices 100、SEO 75；这些仅适用于当时的首页状态，并非全站质量认证。

## 结论及评分（主观判断，不是自动化覆盖率）

- 整体设计 7/10：无额外依赖、本地部署和 SQLite 持久化适合个人使用；服务域依赖用逐级继承串联，`server.mjs` 路由集中，`public/app.js` 超 3300 行，扩展维护成本高。
- 功能完成度 7.5/10：选择题、模拟考、错题复习、题库筛选、真题导入、统计、备份等具备实现与测试；案例/论文/Wiki 有入口及后端实现，但真实模型调用、内容品质和跨浏览器 E2E 未验证，不能声称完全可用。
- 功能逻辑 6.5/10：选择题首答锁定、考试不提前泄露答案及备份恢复有测试；每日目标计算、案例模拟限时存在已复现错误。
- UI/UX 7/10：桌面布局清晰，绿/白低噪声、表单组织合理；移动导航横向滚动缺少可见提示，空数据页缺少明确引导，页面缺少 `<title>`。
- 个人备考体验 6/10：章节练习—复习—统计有闭环；初次启动全空题库，需要配置模型/生成或导入外部真题，学习任务依赖额外准备与模型质量，属于尚待降低的启动门槛。

## 已验证问题

1. **P1 案例模拟超时只显示提示，不锁定服务端写入**：在开始时间后 20 分钟、限时 10 分钟的隔离实例里，`activeCaseExam().remainingSeconds === 0`，但 `saveCaseExamDraft()` 仍返回 `saved:true`。`src/service/case-exam.mjs:215`、`public/app.js:3028`；限时考试规则不成立。
2. **P1 每日目标把未答题计为已答**：构造 `total=10, unanswered=10` 的合法练习记录后，`getStudyPlan()` 返回 `todayAnswered=10, todayDone=true`。`src/service/review.mjs:226`、`src/service/sessions.mjs:499`；学习目标与连续打卡可被空白交卷刷满。
3. **P1 每日目标按 UTC 日而非用户本地日统计**：在东八区 2026-09-25 00:30（UTC 2026-09-24 16:30）的模拟时间，服务把该练习记到 09-24；`src/service/review.mjs:221`、`src/service/review.mjs:225`。若产品定义按 UTC 打卡则需明确标注，当前 UI 称“今天”。
4. **P1 局域网模式没有用户身份验证**：`README.md` 指导 `HOST=0.0.0.0`；`server.mjs:130` 和 `server.mjs:143` 无身份验证即提供学习备份导出、清空数据和更改模型配置接口（`server.mjs:172`、`server.mjs:237`、`server.mjs:265`）。对单人本机回环运行风险较低，局域网中其他可访问者风险高；此项为源码确认，未在真实局域网攻击测试。
5. **P2 页面无标题**：`public/index.html:3` 到 `public/index.html:12` 不含 `<title>`，Lighthouse 的 document-title 审计失败；浏览器标签与辅助技术的可辨识度下降。
6. **P2 空库入口行为不一致**：新库首页章节练习被禁用、真题套卷被禁用，但“开始综合知识模拟”仍可点，点击后才告知题库为空。浏览器实测；`public/app.js:2842`、`public/index.html:167`。
7. **P2 移动导航可发现性弱**：390px 截图中仅露出前几个标签，余下“知识库/资料/管理”在横向滚动外；无滚动提示或移动菜单。`public/styles.css:24`。

1. 优先修复服务端案例计时约束及每日目标两类统计错误，分别补充服务端边界测试。
2. 若需内网访问，增加身份验证/隔离策略；至少明确警示不要直接暴露带写入和配置能力的端口。
3. 增加零题库单击引导（配置模型、导入、生成三条路径），禁用不可开始的模拟按钮并说明原因。
4. 补充页面标题、移动端导航入口与有代表性的浏览器冒烟测试，再考虑服务组合与前端拆分。
