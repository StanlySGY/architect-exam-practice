# 修复需求

依据 `.ccg/tasks/archive/2026-09/project-comprehensive-audit/review.md`，修复影响学习答案保留、练习判分可信度、题库导入隔离和模型运行透明度的问题。

## 范围

- 论文和单案例评分时，将本次提交的作答与评分结果一起持久化；刷新后答案仍可见。
- 活动会话保存题目快照，恢复及交卷使用启动时的题目版本；不得通过会话 API 暴露快照中的正确答案。
- 真题导入使用稳定且来源隔离的 ID，拒绝同批重复 ID，并保留已有导入题的草稿、评分和历史关联。
- OpenAI 兼容请求在各次尝试中正确处理网络失败、超时及 JSON Schema 降级请求的重试，同时尊重外部取消。
- 对论文 AI 评分分数类型、范围和维度合计进行服务端校验。
- 读取 Claude CLI 可提供的 usage 并记账；文档准确说明用量统计只覆盖返回 usage 的供应商。
- `.env` 新建和更新后权限限制为当前用户读写；首页复习说明与 FSRS 调度一致。

## 约束

- 保留当前工作区既有未提交改动，不回退或覆盖。
- 只在上述业务边界改动；不做 `public/app.js` 或 `server.mjs` 的整体拆分。
- 服务端校验不能依赖模型遵守 JSON Schema。
- API 返回给练习页的题目仍须剥离答案和内部快照。

## 验收

- 为答案持久化、会话题目版本隔离、导入 ID 冲突与重复、模型重试和评分数值校验补服务层测试。
- `npm test` 与 `npm run lint` 通过。
- 工作区 diff 只包含本任务修复及原有用户改动，不回退原有改动。
