# 需求：整体功能与交互体验改进

## 背景

项目已经具备章节练习、模拟考试、错题复习、题库管理、主观题、资料、知识库、统计和备份等主要闭环。本轮审查针对当前工作区与最近修复记录，确认仍有五类会影响用户信任或导致数据状态不一致的问题。

## 必须修复

1. 案例限时模拟卷创建后必须固定当时展示的案例内容；题库重新导入或编辑不能改变恢复和判分所依据的题干、小问和参考答案。
2. 删除生成题后，导出的备份必须能够再次导入；已完成练习保留快照时，备份验证应接受快照引用。
3. 学习统计中的“未来 6 天到期合计”必须按每个到期日不重复计数。
4. 知识图谱重绘、筛选、搜索、窗口缩放和重置必须保持当前筛选、颜色和邻域深度设置，图谱不能显示被筛掉的条目。
5. 模型配置中新增/删除供应商或 Agent 行时，必须先保留当前 DOM 中尚未保存的编辑。
6. 已有活动案例模拟时，不能让用户无提示地通过“开始案例模拟”放弃当前卷；应禁用入口并提示恢复，或在确认文案中明确放弃草稿。本轮采用禁用并显示恢复入口。

## 验收标准

- 现有服务 API 和页面契约保持兼容，旧备份仍可导入。
- 为每个修复添加最小回归测试或静态契约断言。
- `npm test`、`npm run lint` 和 `git diff --check` 通过。
- 不改动本轮问题之外的既有工作区修改。
