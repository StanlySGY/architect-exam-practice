# 实施与审查计划

1. 盘点源码、配置、数据、静态资源和测试入口，保留工作树已有改动。
2. 读取前端页面、样式、状态流和后端路由/服务边界，确认报告问题在当前版本的实际表现。
3. 实施安全边界：局域网令牌、管理 API 鉴权、Agent 开关、模型 URL SSRF 防护、CLI 配置隔离和审计记录。
4. 实施考试一致性：服务端 deadline/status、答案 revision、事务内判卷 CAS、论文模拟截止校验。
5. 实施备份可靠性：版本和结构校验、集合/引用/大小限制、事务导入和恢复审计。
6. 补充单元测试、lint/语法门禁并运行完整测试和 diff 检查。
7. 调用 antigravity 与 Claude 对最终变更做双模型审查；若环境权限仍阻断，记录证据并完成本地审查。
8. 评估是否有非显而易见的规范经验需要沉淀，更新审查记录并归档任务。
